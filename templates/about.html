About CampusRetrieve

A centralized Lost & Found Hub for educational institutions

Abstract

CampusRetrieve is a web-based repository designed to solve the inefficiency of manual "Lost and Found" processes in educational institutions. Currently, lost items are reported via scattered WhatsApp groups or physical notice boards, leading to low recovery rates. This project provides a centralized digital platform where students can post details about items they have lost or found.

The system utilizes a Model-View-Controller (MVC) architecture and features File Handling (for image uploads), Search Algorithms (for item filtering), and Database Persistence.

Key Features

Photo Uploads

Users can upload actual photos of "Found" items for visual verification.

Categorized Filtering

Items are tagged (Electronics, Books, ID Cards, Keys) for quick searching.

Status Tracking

Items are clearly marked as "LOST" (Red) or "FOUND" (Green).

One-Click Contact

A "Contact" button immediately opens an email draft to the reporter.

Responsive Design

Works perfectly on mobile phones (crucial for students on campus).

Advanced Search

Filter by status, category, and search keywords instantly.

Advantages

  • Centralization: Eliminates the need to check multiple physical locations
  • Visual Proof: Images reduce confusion between similar items
  • Speed: Real-time updates for immediate claiming
  • Accessibility: 24/7 access from any device
  • Organized: Categorized and searchable database

Limitations

  • Trust Dependence: System relies on user honesty
  • Privacy: Contact details are visible to users
  • Maintenance: Old items need manual deletion
  • Internet Required: Requires online connectivity

Usage Scenarios

Scenario 1: Lost Wallet

Student A loses a wallet. They post a "LOST" report with description. Student B finds it, searches the portal, and emails Student A.

Scenario 2: Found Keys

Student C finds keys and posts a "FOUND" report with photo. The owner sees the photo and immediately claims them.

Scenario 3: Lost Phone

Student D loses phone in cafeteria. Posts details. Later that day, someone reports finding it with matching description.
